STYLE

Picking a look adds its words to every prompt, sets its browser filter, and puts its LoRA (if it has one) in slot A. The list is styles.json: edit it to add or change looks.

LoRAs live in the loras/ folder on the machine running the server. A new file shows up here within a few seconds. Trigger words (a .txt with the same name) are added to the prompt while a LoRA is on.

The reference steers the avatar and the world in the game and the lab (the lab's own slots still work too). Style only puts it just in the painter's style layers, so a portrait of a fisherman gives you its brushwork, not a fisherman. Try strength 0.6–1.0.
