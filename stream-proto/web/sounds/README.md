# Recordings for the game's places (optional)

The game makes every place's sound itself (web/sound.js). A recording can replace any of them: put the file here and
name it in manifest.json, for example

    { "rain": "rain.ogg", "train": "platform-night.mp3" }

It is played in a loop, cross-fading like the made ones. The names: room, fan, murmur, crowd, children, street, rain,
wind, birds, night, train, water, clock, kitchen, bells, typing, hospital. Use recordings you made or ones whose licence
allows it (CC0 is simplest), and keep loops 30 s or longer so the repeat isn't heard.
